# Amazon KR Skill

一个可以直接生产亚马逊图片成品的 Codex Skill。默认交付实际图片文件，而不是只输出策划、提示词或审核意见。它可制作商品主图、副图、白底图、功能信息图、使用与安装图、生活场景、材质细节、款式对比和 A+ 模块，也可完成修改、尺寸适配与视觉验收。

适用品类包括但不限于家居、厨具、五金、消费电子、美妆容器、服饰纺织、家具、宠物用品、运动用品和汽车配件。

它的核心原则是：**产品事实优先于画面华丽度**。先锁定结构、比例、部件、材质、表面处理、颜色、真实使用方式和可证实卖点，再生成场景；产品资产通过后固定复用，文字、箭头、卡片和最终尺寸由确定性排版完成。

挂钩不是本 Skill 的品类边界，只是最早用于提炼失败模式和验收方法的历史案例。

## 默认交付行为

用户说“制作、生成、设计、出一套图片”时，Skill 必须直接执行到成品：

1. 建立产品事实表并确认关键材质。
2. 制作并审核固定产品母版。
3. 生成或编辑场景、道具和使用状态。
4. 完成文字、箭头、图标和尺寸排版。
5. 导出实际主图、副图或 A+ 文件。
6. 逐张目视检查并程序校验。

只有用户明确说“只需要方案、提示词、文案或审核报告”时，才可以不生成图片。缺少必要产品图时，Skill 会要求用户补充图片，不会凭空虚构产品。

## 主图和 A+ 复刻

Skill 可以直接根据参考图复刻亚马逊主图、副图或整套 A+。复刻遵循两套来源：

- 参考图控制构图、角度、产品占比、背景、光影、留白、字体层级、卡片和模块节奏。
- 用户产品图控制产品结构、材质、颜色、Logo、配件、包装、使用方式和卖点。

复刻不是把参考图中的竞品替换个颜色。Skill 会先拆解参考版式，再制作用户产品母版，重建背景和排版，替换全部产品、品牌、文字、尺寸与卖点，最后分别检查“产品是否准确”和“视觉是否像参考”。

主图复刻重点匹配机位、旋转角度、裁切、相对大小、白底、光线和接触阴影；A+ 复刻则逐屏匹配栅格、信息层级、配色、图文比例和场景语言，并按实际模块尺寸重新输出。

## 生成前的材质提醒

当材质会影响商品真实性而用户尚未说明时，Skill 会主动提醒确认：

- 基础材质，例如不锈钢、铝、ABS、亚克力、玻璃、陶瓷、硅胶、木材或织物
- 表面工艺，例如拉丝、镜面、电镀、喷粉、阳极氧化、磨砂、上釉或压纹
- 光泽度、纹理方向、纹理尺度和准确颜色
- 哪张产品近景图是材质基准

例如，用户只说“增强金属质感”时，Skill 不应直接生成夸张镜面效果，而要区分拉丝不锈钢、抛光钢、镀铬、阳极氧化铝和喷粉金属。

## 使用方式

将仓库作为 Codex Skill 来源使用，或把整个目录放入支持的 Skill 目录。示例请求：

```text
Use $amazon-kr to directly produce final Amazon listing and A+ image files from my product sources.
```

也可以直接要求：

```text
使用 $amazon-kr，根据产品图先建立产品事实表。如果材质、表面工艺或颜色信息不足，生成前提醒我确认，然后直接制作并交付1张亚马逊主图和5张副图成品。
```

制作 A+：

```text
使用 $amazon-kr，根据这些产品图直接制作一套亚马逊A+图片。使用后台模块截图中的尺寸，最终交付可以直接上传的图片文件，不要只给方案或提示词。
```

复刻参考图：

```text
使用 $amazon-kr，根据参考图复刻这套亚马逊主图和A+。参考图只控制构图、光影和版式；产品结构、材质、Logo、配件和卖点必须以我的产品资料为准。最终直接交付图片成品。
```

## 图片校验

安装依赖后，可检查一个目录内的图片是否全部为指定尺寸和格式：

```bash
python -m pip install -r requirements.txt
python scripts/validate_images.py ./output --width 970 --height 300 --format JPEG
```

脚本支持 JPEG/PNG；返回码 `0` 表示全部通过，`1` 表示发现不合格图片，`2` 表示路径或输入错误。

## 适用边界

这个 Skill 面向 Amazon A+ 和商品视觉生产，不覆盖广告投放、PPC、选品、库存、财务或账号运营。仓库中的 970×300、1464×600 等尺寸是历史项目事实，不被当作永久的平台通用规则；判断当前合规性时应核对实际上传模块和 Amazon 官方资料。

## 来源说明

本 Skill 最初从一个吸盘挂钩项目的多轮制作记录中归纳，但方法已抽象为通用实物商品流程。历史案例贡献了固定产品资产策略、结构与物理逻辑验收、600×450 与 1464×600 的无变形适配，以及对产品漂移、错误材质、突兀白边、模糊边框和错误背景取色的纠正。
